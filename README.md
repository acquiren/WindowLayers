# WindowLayers（窗口层级工具）

一个轻量的 Windows 托盘工具，用快捷键将当前活动窗口置顶或持续置底，并在目标窗口周围显示可配置的动态彩色边框。启动后仅显示托盘图标，需要修改设置时再打开配置界面。

## 功能

- 对当前活动窗口切换置顶或置底；同一时间各保留一个目标窗口。
- 置底窗口被激活后，工具会继续将它维持在其他普通应用窗口下方。
- 为置顶和置底分别设置边框颜色，并调整边框粗细、动画速度或关闭动画。
- 从托盘打开设置、取消置顶或置底、切换开机自启动以及退出程序。
- 设置窗口打开时会接管唯一的置顶名额；隐藏设置窗口后释放该名额。
- 支持 Windows 高 DPI 显示；空间不足时可滚动设置区域。

## 环境要求

- Windows。
- 从源码构建：.NET 6 SDK，包含 Windows Forms 开发支持。
- 运行普通构建产物：.NET 6 Desktop Runtime。构建输出目录中的 `.exe`、`.dll` 和运行配置文件应一起保留。

## 构建与运行

在项目根目录执行：

```powershell
dotnet build WindowLayers.csproj -c Release
```

随后运行 `bin/Release/net6.0-windows/WindowLayers.exe`。也可以直接从源码启动：

```powershell
dotnet run --project WindowLayers.csproj -c Release
```

程序启动后在系统托盘运行，不会自动打开设置窗口。再次启动时，如果已有实例在运行，程序会提示并退出。

## 使用方法

| 操作 | 默认快捷键或入口 |
| --- | --- |
| 切换当前活动窗口置顶 | `Ctrl + Alt + T` |
| 切换当前活动窗口置底 | `Ctrl + Alt + B` |
| 打开设置 | 双击托盘图标，或右键图标选择“打开设置” |
| 取消置顶、取消置底 | 托盘右键菜单 |
| 开机自启动 | 托盘右键菜单中的“开机自启动” |
| 退出程序 | 托盘右键菜单中的“退出” |

在设置界面中点击快捷键输入框，再按下包含修饰键的组合键，最后点击“保存设置”。置顶和置底不能使用同一组合键。关闭设置窗口或点击“隐藏到托盘”后，程序继续在后台运行。

置顶、置底操作针对按下快捷键时的活动窗口。设置界面显示期间，它占用置顶名额；原先置顶的窗口会被取消置顶，隐藏设置界面后不会自动恢复。

## 设置与开机自启动

程序将设置保存到 `%APPDATA%\WindowLayers\settings.json`。开机自启动开关在当前用户的 Windows 启动项中登记当前程序路径；移动程序后，建议关闭并重新开启该选项。

## 已知限制

- 某些以管理员权限运行的窗口可能需要以管理员身份运行本工具，才能更改其层级。
- 置底是通过持续调整窗口顺序实现的；个别全屏程序或特殊窗口管理行为可能影响效果。
- 本项目仅面向 Windows，未提供其他系统版本。

## 项目文件

- `Program.cs`：托盘、快捷键、窗口层级、动态边框和设置界面。
- `WindowLayers.csproj`：.NET 项目配置。
- `WindowLayers.ico`、`WindowLayers.png`：程序图标及其图片版本。

`bin/` 是构建输出，`obj/` 是 .NET 构建中间文件；两者均未纳入 Git。
